# Fixed-world land fill: evidence and implementation contract

Research date: October 3, 2026. Only this document changed in this batch. Existing importer, widget and tests were read without editing. Measurements used the previously verified temporary archive, with no network acquisition, extracted members, generated repository asset, dependency installation or live HamClock access. This is a proposed rendering contract and bounded experiment, not topology certification or an implemented filled map.

## Primary evidence

- [Esri Shapefile Technical Description, printed pages 8–9](https://www.esri.com/content/dam/esrisites/sitecore-archive/Files/Pdfs/library/whitepapers/pdfs/shapefile.pdf#page=12): Polygon parts are closed rings; clockwise outlines and counterclockwise holes indicate interior side; multiple outlines are possible; part order has no meaning. Clean geometry forbids segment intersections and permits different rings to touch at vertices. The specification is evidence for an original reader, not permission to copy implementation or redistribute the paper. **High confidence in documented semantics; source conformance still requires inspection.**
- [Qt 6.11.2 QPainterPath](https://doc.qt.io/qt-6.11/qpainterpath.html#setFillRule): explicitly select a fill rule; its default is OddEvenFill. WindingFill supplies an oriented fill model suitable for SHP ring direction. The [simplified method](https://doc.qt.io/qt-6.11/qpainterpath.html#simplified) merges subpaths and changes the rule to OddEvenFill: do not call it as an undocumented repair. [QPainter clipping](https://doc.qt.io/qt-6.11/qpainter.html#setClipRect) operates in logical painter coordinates. **High confidence in documented API behavior; native raster results require tests.** Use APIs available at the project's Qt 6.4 minimum, not newer caching APIs; Pi/Qt 6.4 execution is unverified.
- [RFC 7946 section 3.1.9](https://www.rfc-editor.org/rfc/rfc7946#section-3.1.9) recommends cutting antimeridian crossings; its example splits a 170E/170W rectangle into two polygons. This is useful future interchange guidance, not a declaration that the measured SHP is GeoJSON or that planar longitude differences imply shortest spherical edges. **High confidence.**
- [Natural Earth terms](https://www.naturalearthdata.com/about/terms-of-use/) place the website's raster/vector datasets in the public domain and permit modification and redistribution without compulsory attribution. Preserve voluntary credit, source/version/hash and transformations. This source-specific statement does not clear all product naming, dependencies or legal obligations. **High confidence in published dataset permission.**

## Proposed first contract: pinned fixed planar world

1. Consume only the audited generated immutable points/rings/records contract. Assert offsets/counts and complete coverage before constructing cached paths, with safe arithmetic. No runtime file/ZIP/user polygon loader or network path.
2. Project land coordinates directly: `x=(longitude+180)/360`, `y=(90-latitude)/180`. Land **+180 maps to x=1; -180 maps to x=0**. Do not reuse `map_project_equirectangular`, which deliberately wraps +180 for point markers. The existing coastline splitter remains unchanged and is never used to close land rings.
3. For each source record create its own `QPainterPath`, explicitly WindingFill, preserving every ring's point order in distinct closed subpaths. Reflection of latitude into screen y reverses all directions together and preserves exterior/hole opposition. Draw records independently with the same land brush, no pen; then current coastline, route and markers. Do not combine independent records under odd-even parity, erase earlier land with a hole's sea brush, infer holes from array position, simplify or repair paths.
4. This interprets the pinned data as supplied planar closed paths. No automatic spherical unwrap or shortest-edge decision. Preserve Antarctica's x=1→0 bottom boundary. New ordinary >180-degree edges or new source hashes require re-review; an arbitrary 170E/170W ring is outside this initial source acceptance policy.
5. Keep the current 2:1 geographic `mapBounds`, empty/tiny handling, sea-colored letterbox and clip in widget coordinates before translate/scale. Save/restore painter state around normalized land/coast drawing. No polygon clipping transform is needed for this fixed complete world with verified endpoint bounds. Clip remains necessary for strokes/markers and paint containment; clipping does not repair a bad topology.
6. Use existing light/dark/System behavior. Land colors must follow the approved soft composition and be checked against coast/route/marker contrast; color choice and accessibility claims remain unapproved until native inspection. Map textual route/station information must remain available.

Confidence: **high** in direct projection and source seam observations; **medium** in WindingFill as the best SHP interpretation; **unknown** actual microloop/native raster behavior and general topology. Release gate: experiment below, independent audit, root integration, computer inspection and hardware evidence separately.

## Numerical and executable acceptance fixtures

- Projection: `(-180,90)=(0,0)`, `(180,90)=(1,0)`, `(-180,-90)=(0,1)`, `(180,-90)=(1,1)`, `(0,0)=(0.5,0.5)`. Interior neighboring floats keep their side; ±180 identity stays distinct. NaN/Inf/out-of-bounds rejected before path construction.
- Synthetic CW rectangle with CCW hole; hole-first order equivalent; two CW exteriors in one record; nested CW island inside hole; independent overlapping records remain filled; reversed-all direction gives identical nonzero-fill interior. Boundary queries are excluded from strict inside/outside expectations and tested separately as rendering boundaries.
- Polar rectangle `(-180,-90),(-180,-80),(180,-80),(180,-90),(-180,-90)` fills `(0,-85)` and excludes `(0,-70)`; full-width bottom edge does not collapse. Two explicit seam-edge rectangles cover 170E…180E and 180W…170W (numeric longitude -180…-170), leaving Greenwich ocean. A lone unlabelled 170E/170W ring must not be admitted as a short-crossing polygon.
- Record79 exact microloop: compare QPainterPath.contains and raster interior samples away from boundaries; inspect subpixel behavior at normal and enlarged scale. Expected high-level land near `(-132,53.5)` and nearby ocean must be independently selected from source geometry. No point removal to make a test pass.
- Pinned-source interior ray diagnostic currently gives London `(-0.1278,51.5074)` land record84; Tokyo `(139.6917,35.6895)` land72; Los Angeles `(-118.2437,34.0522)` land96; Atlantic `(-30,0)` ocean; Pacific `(-140,0)` ocean; `(51,42)` hole/ocean; Antarctica `(0,-85)` land8. These expected classifications need independent recomputation and are generalized dataset checks, not navigation accuracy.
- Raster tests sample safely away from antialiased edges at several map sizes; assert the hole stays sea, no seam chord crosses the middle, no paint outside clip, routes/DE/DX still visible. Native light/dark/System at seven-inch target, large view and empty/tiny view; distinguish automated images from actual computer-controlled app observations. Measure actual Pi3/Pi4 startup/path memory/repaint separately, no desktop performance inference.
