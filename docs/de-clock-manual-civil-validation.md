# Manual DE civil conversion validation

October 11, 2026. This original, stateless QtCore adapter converts an injected actual UTC timestamp plus an explicitly validated manual offset into owned DE civil fields. It keeps actual UTC, the supplied offset and a distinct shifted calendar encoding separate. It does not read a clock, activate native controls, select a timezone mapper, persist settings or establish source accuracy.

Complete desired configuration and caller-supplied bounds validate first. Missing source remains missing rather than epoch zero. Present Automatic remains explicitly unresolved, with no UTC/manual fallback. In manual mode, actual source bounds are checked before addition; signed64 addition is checked without negating the most-negative offset; display bounds are checked before any Qt calendar decoding. Only a bounded sum reaches the existing guarded UTC-shaped decoder. Year1..9999 and seconds0..59 are explicit replacement policies, not discovered original HamClock numeric limits. Invalid input leaves caller data unchanged.
