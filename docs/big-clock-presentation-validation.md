# Big Clock digital presentation — CB1a validation

October 11, 2026. Original pure formatter for explicitly injected Gregorian civil fields. This increment formats bounded owned text; it neither reads a clock nor converts UTC or station timezone data. No Big Clock screen, analog face, alarms, weather, persistence or system-clock adjustment is activated.

The reviewed input contract separates actual and preview civil values in UTC and DE. A selected preview whose value is missing remains missing; no fallback to actual or another zone. Valid time remains available with Unknown synchronization; Synchronized evidence cannot fabricate a missing value. Every present civil value is validated, including hidden/unselected values. Preferences are copied without rewriting. Analog desire is explicitly UnsupportedFace, with empty time/date, rather than silently rendered digitally.

Replacement formatter policy is proleptic Gregorian year 1..9999, valid month/day, hour 0..23, minute/second 0..59. Leap seconds, historical local calendar reconstruction and timezone conversion are excluded. ASCII 24-hour or 12-hour AM/PM time has two-digit hours; midnight is 12 AM and noon 12 PM. Date text is YYYY-MM-DD. Seconds and date can be hidden independently. Owned fixed arrays include NUL terminators and zero unused bytes; successful formatting requires no heap allocation. Invalid supplied inputs reject rather than normalize.
