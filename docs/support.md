# HamClock Pro support

HamClock Pro is a free, open-source amateur-radio dashboard by Christopher Law (KM7IBM). It is an independent project, not affiliated with the original HamClock or its author.

## Get help or report a problem

Open an issue on GitHub: <https://github.com/the-chrislaw/hamclock-pro/issues>

Please include:

- your device (for example iPhone 16, iPad Air, Mac, Raspberry Pi 4) and its system version,
- the HamClock Pro version (Settings, at the bottom),
- what you did, what you expected and what happened, and a screenshot if you can.

Please don't post passwords, API keys or other private details in an issue.

## Common questions

**A pane says "Set up".** That pane needs something from you first, such as your callsign, a DX cluster node or an account for an optional service. Open Settings.

**A pane says "Stale" or "Offline".** The data provider couldn't be reached. HamClock Pro shows the last data it had and its age, and keeps retrying.

**Where does the data come from?** Directly from public providers such as NOAA, NASA, CelesTrak and amateur-radio services. See the [privacy policy](../privacy/) for the full list.
