# AD1C Country Files (cty.dat)

`src/widgets/dxcluster/data/cty.dat` is the AD1C Country Files "cty.dat" (Jim Reisert AD1C, https://www.country-files.com/), bundled unmodified and used offline for callsign prefix to DXCC entity lookups. It is not fetched at run time.
