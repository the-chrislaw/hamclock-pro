# Countdown presentation validation — October 11, 2026

CU0 converts a validated immutable countdown snapshot into an owned view. It adds no stored presentation state, Qt UI, running timer, acknowledgment token, persistence, network, scheduler, sound or hardware operation. Source code is an original implementation; no full original HamClock parity or certification is claimed.

The explicit replacement display policy rounds any positive remaining duration up to a whole second in both Running and Paused states. One nanosecond therefore displays 00:00:01 rather than premature zero. Configured display uses the same policy; exact raw nanoseconds and run identity remain available. Hours do not wrap after 24; the seven-day model maximum renders 168:00:00 in at most nine bytes. This numeric format/rounding is not established original behavior.

Structural validation rejects unknown phases, invalid configured/remaining ranges, Idle with partial duration or pending expiry, active phases without a run identity/positive remaining, active pending expiry, and Expired without identity or zero remaining. Expired stays zero and Expired after acknowledgment, with truthful pending/cleared status. Structural validation proves neither historical service transitions nor token lifetime. Dismiss availability is metadata; it creates no acknowledgment authority.
