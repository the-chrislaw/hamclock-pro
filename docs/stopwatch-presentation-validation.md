# Offline stopwatch presentation validation

October 11, 2026. This original pure adapter keeps the displayed stopwatch value fixed while supplied model elapsed continues advancing. Explicit Hold and Release are separate commands; stopping or resetting the model clears the hold. Repeated Hold retains the first captured value. These release/reset/stop interaction policies are named replacement choices, not claims about undocumented original gestures.

The formatter truncates nonnegative nanoseconds to centiseconds and emits owned HH:MM:SS.cc text without a 24-hour wrap. Hours grow through the signed64 duration maximum; output is at most 16 bytes. Every incoming model snapshot is validated, including all active and unused lap cells. Invalid phase, elapsed, lap metadata or command rejects without changing any stored view. Temporary copies and formatting precede nonthrowing swap/move commit; allocation exceptions preserve stored state. Returned views own their strings and duration values.

Author strict C++17 warning-as-error address/undefined-behavior sanitizer tests passed 85 checks. Root configured and built locally, all 17 CTest tests passed, and make verify compiled and ran the new presentation regression with existing model and executable checks. Independent source, adversarial test and fresh whole-build evidence and final hashes are recorded separately in workstreams/stopwatch-presentation-audit.md. The earlier stopwatch state model and native map validation remain distinct evidence.

Primary guide behavior was independently reviewed: original Lap holds the display while elapsed continues, and stopwatch display includes hundredths. This pure adapter supplies those foundations. It does not open a native view, schedule refreshes, map Run/Stop controls, select colors or implement Exit, countdown, alarms or Big Clock. No new computer-control UI acceptance is claimed; the next native dialog must be built, independently audited and actually exercised before publishing UI changes.

No original HamClock code or third-party implementation was copied. This scoped provenance review is not full legal certification. The adapter adds no dependency, transport, persistence or hardware operation. Validation uses the host Mac; real Pi 3/Pi 4/touch, full accessibility compliance and complete final-original timer parity remain unverified. Allocation-failure injection and any remaining untested boundary cases are identified in the independent audit rather than inferred from passing normal tests.
